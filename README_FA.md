# Auto Anvil — Fabric 1.21.11

نسخه 0.2.0 پروژه‌ی توسعه‌یافته‌ی Auto Enchant است.

## قابلیت‌ها
- پنل داخل Anvil برای روشن/خاموش کردن Auto Enchant.
- صفحه‌ی انتخاب enchantment و level.
- تشخیص ابزارها و زره‌های موجود در inventory.
- صف چند آیتمی برای انجام پشت‌سرهم.
- توقف خودکار وقتی XP کافی نیست و ادامه بعد از رسیدن XP کافی.
- planner برای مرتب‌کردن ترکیب کتاب‌ها با توجه به prior-work penalty و هزینه‌ی تقریبی انویل.
- بررسی نهایی هزینه توسط خود سرور؛ مود قانون انویل را دور نمی‌زند.
- کلیدهای پیش‌فرض: O = Config، P = Toggle، K = Start/Stop.

## ساخت
JDK 21 لازم است. در ویندوز: `gradlew.bat build`

> این محیط امکان اجرای Gradle/Java و دانلود dependencyهای Minecraft را ندارد؛ بنابراین این نسخه به‌صورت source project ارائه می‌شود و JAR نهایی باید روی سیستم توسعه ساخته شود.
